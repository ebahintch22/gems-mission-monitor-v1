# Guide de remplissage de la fiche de contrôle terrain des bâtiments

## 1. Objectif de la fiche

La fiche de contrôle terrain sert à vérifier, bâtiment par bâtiment, la cohérence entre le plan de situation fourni et la réalité observée sur le site.

Elle permet de noter :

- les bâtiments qui existent réellement sur le terrain ;
- les bâtiments correctement représentés sur le plan ;
- les bâtiments absents du plan mais présents sur le terrain ;
- les bâtiments présents sur le plan mais inexistants sur le terrain ;
- les cas de scission ou de regroupement de bâtiments ;
- les corrections utiles pour mettre à jour la base cartographique.

La fiche doit être remplie avec soin, de manière lisible, et accompagner le plan de situation correspondant.

## 2. Avant de commencer la vérification

1. Vérifier que vous disposez du bon plan de situation pour le site à visiter.
2. Vérifier que le nom du site et le code du site correspondent à la fiche.
3. Identifier les bâtiments représentés sur le plan.
4. Préparer le matériel nécessaire : stylo, plan imprimé, fiche de contrôle, téléphone ou tablette Kobo, GPS si disponible.
5. Lire les indicateurs déjà renseignés dans la partie **Avant vérification**.

## 3. Remplir les informations générales du site

Dans l’en-tête de la fiche, compléter ou vérifier les informations suivantes :

- **Région** : région administrative du site.
- **Ministère** : ministère ou institution de rattachement.
- **Localité** : ville, commune ou localité concernée.
- **Code du site** : code unique du site.
- **Nom du site** : nom officiel ou nom couramment utilisé.
- **Numéro de l’équipe de vérification** : numéro de l’équipe terrain.
- **Date de la vérification** : date réelle de passage sur le site.
- **Nom de l’enquêteur** : nom de la personne qui remplit la fiche.

Si une information préremplie est incorrecte, ne pas l’effacer complètement. La corriger lisiblement et signaler la correction dans les observations générales.

## 4. Lire les indicateurs avant vérification

Cette partie est normalement issue de la carte ou de la base de données.

Elle indique :

- le nombre total de bâtiments représentés sur la carte ;
- le nombre de bâtiments déjà attribués à un site ;
- le nombre de bâtiments non attribués ;
- l’échelle de la carte ;
- la date ou la source cartographique utilisée.

Ces informations servent de référence. Elles ne doivent pas être modifiées sur le terrain, sauf instruction contraire du superviseur.

## 5. Remplir les indicateurs après vérification

Cette partie est à compléter après le contrôle du site.

Renseigner :

- **Nombre de bâtiments vérifiés sur le terrain** : nombre total de bâtiments effectivement contrôlés.
- **Nombre de bâtiments conformes** : bâtiments qui existent et correspondent globalement au plan.
- **Nombre de bâtiments omis** : bâtiments présents sur le terrain mais absents du plan.
- **Nombre de bâtiments commis** : bâtiments présents sur le plan mais inexistants sur le terrain.
- **Nombre de bâtiments scindés** : cas où un bâtiment du plan correspond à plusieurs bâtiments sur le terrain.
- **Nombre de bâtiments regroupés** : cas où plusieurs bâtiments du plan correspondent à un seul bâtiment sur le terrain.
- **Observations générales** : remarques utiles sur le site, les difficultés rencontrées ou les corrections importantes à faire.

Les totaux doivent être cohérents avec les lignes remplies dans le tableau de relevé.

## 6. Remplir le tableau de relevé bâtiment par bâtiment

Chaque ligne du tableau correspond à un bâtiment contrôlé ou à une anomalie à signaler.

### 6.1. Colonne `N° carte`

Inscrire le numéro du bâtiment tel qu’il apparaît sur le plan de situation.

Cette colonne est volontairement vide au départ. Elle doit être remplie sur le terrain par l’enquêteur.

Si le bâtiment est absent du plan, laisser cette colonne vide ou inscrire `Omis`.

### 6.2. Colonne `N° Kobo`

Inscrire le numéro ou l’identifiant du bâtiment saisi dans KoboToolbox.

Si le bâtiment n’a pas encore été saisi dans Kobo, laisser la case vide provisoirement, puis la compléter après la saisie.

### 6.3. Colonne `Existence terrain`

Cocher une seule option :

- **Oui** : le bâtiment existe sur le terrain.
- **Non** : le bâtiment n’existe pas sur le terrain.
- **Partiellement** : le bâtiment existe en partie, est détruit partiellement, inaccessible partiellement ou très différent de ce qui est représenté.

### 6.4. Colonne `Conformité emprise`

Cocher une seule option :

- **Oui** : la forme, la position et la taille du bâtiment correspondent globalement au plan.
- **Non** : l’emprise ne correspond pas au terrain.
- **Non concerné** : cas où la conformité ne peut pas être évaluée, par exemple bâtiment omis ou bâtiment inaccessible.

### 6.5. Colonne `Écarts constatés`

Décrire brièvement l’écart observé.

Exemples :

- bâtiment plus grand que sur le plan ;
- bâtiment déplacé ;
- bâtiment absent ;
- bâtiment nouvellement construit ;
- bâtiment démoli ;
- contour mal orienté ;
- plusieurs bâtiments confondus en un seul.

La description doit être courte mais suffisamment précise pour permettre une correction cartographique.

### 6.6. Colonne `Type d’écart`

Indiquer le type d’écart principal parmi les cas suivants :

- **Aucun écart** : le bâtiment existe et correspond au plan.
- **Omis** : le bâtiment existe sur le terrain mais n’apparaît pas sur la carte.
- **Commis** : le bâtiment apparaît sur la carte mais n’existe pas sur le terrain.
- **Scission** : un bâtiment de la carte correspond à plusieurs bâtiments sur le terrain.
- **Regroupement** : plusieurs bâtiments de la carte correspondent à un seul bâtiment sur le terrain.

Ne choisir qu’un type principal par ligne. Les détails doivent être ajoutés dans les commentaires.

### 6.7. Colonne `Bâtiments concernés (IDs carte)`

Utiliser cette colonne pour préciser les numéros des bâtiments concernés par un cas complexe.

Exemples :

- pour un regroupement : `B03, B04, B05` ;
- pour une scission : indiquer le numéro du bâtiment initial, par exemple `B07` ;
- pour un bâtiment omis : laisser vide ou inscrire `Nouveau bâtiment`.

### 6.8. Colonne `Affectation`

Indiquer l’usage principal du bâtiment.

Exemples :

- administratif ;
- scolaire ;
- sanitaire ;
- logement ;
- stockage ;
- technique ;
- commercial ;
- autre.

Si l’usage est incertain, écrire `à confirmer`.

### 6.9. Colonne `Croquis / dimensions`

Cette colonne sert surtout pour les bâtiments omis ou les emprises très incorrectes.

Indiquer, si possible :

- la longueur approximative en mètres ;
- la largeur approximative en mètres ;
- une référence au croquis fait sur le plan ;
- toute indication permettant de reconstituer l’emprise.

Exemple :

```txt
Long. 18 m
Larg. 7 m
Croquis réf. A
```

Pour un bâtiment omis, tracer son emplacement approximatif sur le plan et reporter la même référence dans cette colonne.

### 6.10. Colonne `Commentaires`

Ajouter toute information utile non couverte par les autres colonnes.

Exemples :

- bâtiment inaccessible ;
- site fermé au moment du passage ;
- information donnée par le responsable du site ;
- bâtiment en construction ;
- bâtiment démoli récemment ;
- doute sur l’affectation ;
- numéro Kobo associé à plusieurs bâtiments.

## 7. Gérer les cas particuliers

### 7.1. Bâtiment conforme

1. Renseigner le `N° carte`.
2. Renseigner le `N° Kobo`.
3. Cocher **Oui** dans `Existence terrain`.
4. Cocher **Oui** dans `Conformité emprise`.
5. Indiquer `Aucun écart` dans `Type d’écart`.
6. Compléter l’affectation si elle est connue.

### 7.2. Bâtiment omis

Un bâtiment est **omis** lorsqu’il existe sur le terrain mais n’est pas représenté sur le plan.

1. Laisser `N° carte` vide ou inscrire `Omis`.
2. Renseigner le `N° Kobo` si le bâtiment est saisi.
3. Cocher **Oui** dans `Existence terrain`.
4. Cocher **Non concerné** dans `Conformité emprise`.
5. Indiquer `Omis` dans `Type d’écart`.
6. Décrire le bâtiment dans `Écarts constatés`.
7. Renseigner les dimensions approximatives.
8. Tracer un croquis sur le plan et indiquer sa référence.

### 7.3. Bâtiment commis

Un bâtiment est **commis** lorsqu’il apparaît sur le plan mais n’existe pas sur le terrain.

1. Renseigner le `N° carte`.
2. Laisser `N° Kobo` vide.
3. Cocher **Non** dans `Existence terrain`.
4. Cocher **Non concerné** dans `Conformité emprise`.
5. Indiquer `Commis` dans `Type d’écart`.
6. Préciser la raison dans les commentaires : démoli, jamais existé, doublon, erreur de carte, inaccessible ou autre.

### 7.4. Scission

Une **scission** signifie qu’un bâtiment représenté sur la carte correspond en réalité à plusieurs bâtiments distincts sur le terrain.

1. Renseigner le `N° carte` du bâtiment initial.
2. Indiquer `Scission` dans `Type d’écart`.
3. Dans `Bâtiments concernés`, reporter le numéro du bâtiment initial.
4. Dans `Commentaires`, indiquer le nombre de bâtiments observés sur le terrain.
5. Ajouter les numéros Kobo des bâtiments terrain correspondants.
6. Si nécessaire, faire un croquis pour montrer la séparation réelle.

Exemple de commentaire :

```txt
Bâtiment carte B12 scindé en 3 bâtiments terrain : Kobo 14, 15 et 16.
```

### 7.5. Regroupement

Un **regroupement** signifie que plusieurs bâtiments représentés séparément sur la carte correspondent à un seul bâtiment sur le terrain.

1. Inscrire dans `Bâtiments concernés` les numéros des bâtiments de la carte.
2. Indiquer `Regroupement` dans `Type d’écart`.
3. Renseigner le `N° Kobo` du bâtiment unique observé sur le terrain.
4. Expliquer la situation dans `Commentaires`.
5. Si nécessaire, faire un croquis sur le plan.

Exemple de commentaire :

```txt
Bâtiments carte B04, B05 et B06 regroupés en un seul bâtiment terrain : Kobo 08.
```

## 8. Utiliser les pages intercalaires

Les pages intercalaires servent à poursuivre le relevé lorsque la page principale ne suffit pas.

Pour chaque intercalaire :

1. Vérifier que le code et le nom du site sont correctement repris.
2. Indiquer le numéro d’ordre de l’intercalaire.
3. Continuer le remplissage du tableau selon les mêmes règles.
4. Ne pas recommencer la numérotation des bâtiments si elle se poursuit depuis la page principale.
5. Veiller à ce que chaque intercalaire reste associé au bon plan et au bon site.

## 9. Bonnes pratiques de remplissage

- Écrire lisiblement.
- Utiliser les mêmes numéros que sur le plan.
- Ne pas inventer un numéro Kobo avant la saisie réelle.
- Ne pas modifier les indicateurs avant vérification sans instruction.
- Signaler les doutes dans les commentaires.
- Faire un croquis dès qu’un bâtiment est omis, scindé ou regroupé.
- Vérifier la cohérence entre les totaux et les lignes du tableau.
- Informer le superviseur si le plan ne correspond pas du tout au terrain.

## 10. Vérification finale avant remise

Avant de remettre la fiche :

1. Vérifier que les informations générales sont complètes.
2. Vérifier que chaque bâtiment contrôlé a une ligne.
3. Vérifier que les cas omis, commis, scindés et regroupés sont bien expliqués.
4. Vérifier que les croquis sont référencés dans le tableau.
5. Vérifier que les indicateurs après vérification sont renseignés.
6. Vérifier que les pages intercalaires sont numérotées.
7. Remettre la fiche avec le plan de situation correspondant.

Une fiche bien remplie doit permettre à l’équipe cartographique de comprendre les corrections à apporter sans devoir recontacter systématiquement l’enquêteur.
